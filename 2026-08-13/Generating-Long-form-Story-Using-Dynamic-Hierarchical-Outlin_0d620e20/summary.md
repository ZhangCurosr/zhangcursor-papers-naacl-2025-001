# 论文速读：Generating-Long-form-Story-Using-Dynamic-Hierarchical-Outlining-with-Memory-Enhancement

## 一句话总结
论文提出 DOME（Dynamic Hierarchical Outlining with Memory-Enhancement），结合动态层次大纲机制（DHO）与时序知识图谱记忆增强模块（MEM），解决长篇小说生成中长期存在的**情节不连贯**与**上下文冲突**问题。

## 研究问题与动机
- **记忆局限性**：LLM 的自注意力机制存在长距离依赖问题，难以精确回忆上下文，导致语义层面出现上下文不一致。
- **规划困难**：现有方法使用的固定大纲缺乏灵活性，无法适应创作过程中的不确定性，常导致情节重复或冲突；而无人类交互的自由生成又缺乏宏观层面的合理叙事规划，影响情节完整性。
- **评估困难**：现有长篇小说质量评估主要依赖人工，耗时费力，缺乏高效的自动评估手段。
- **现有方法缺陷**：基于 plan-write 的两阶段方法中，大纲一旦固定便无法调整，易引发情节不连贯；而完全依赖人类交互的方法虽灵活但缺乏整体叙事线的引导。

## 核心贡献（创新点）
- **动态层次大纲（DHO）机制**：融合小说写作理论于粗大纲生成，并在写作过程中动态调整细大纲以适配不确定性，提升情节连贯性；相比固定大纲方法（如 DOC），其本质区别在于将大纲规划与写作阶段融合而非分离。
- **基于时序知识图谱的记忆增强模块（MEM）**：利用 TKG 存储和检索已生成内容，结合 LLM 进行语义过滤，提供准确简洁的参考内容以降低上下文冲突；相比直接拼接 KG 知识的方法，其本质区别在于引入 LLM 语义筛选机制保证信息简洁性与相关性。
- **自动冲突检测评估方法（Temporal Conflict Analyzer）**：基于 TKG 信息表示规则与 LLM 结合，自动检测上下文冲突并以冲突率（CR.）量化；填补了长篇小说自动评估工具的空白，相比仅依赖人工评估的方法，实现高效客观的自动评测。

## 方法详解
DOME 整体流程分为三个阶段：粗大纲规划 → 细大纲动态生成 → 故事逐段写作，每步均通过 MEM 查询相关上下文。

- **粗大纲生成**：基于用户输入 I 和小说写作理论 WT（Campbell 五阶段理论），生成覆盖完整故事结构的大纲：$R = LLM(WT, I, P_{rough\_outline})$。
- **细大纲动态扩展**：在写作阶段 i，根据粗大纲部分 $r_i$ 及 MEM 返回的相关内容 $RInfo_i$，动态生成细大纲 $d_i = LLM(r_i, RInfo_i, P_{detailed\_outline})$，每个粗大纲展开 M（本文设为 3）个细大纲，实现对生成不确定性的自适应调整。
- **故事片段生成**：基于每个细大纲 $do_i^t$ 及从 KG 查询的内容 $DInfo_i^t$，生成故事片段 $s_i^t = LLM(do_i^t, DInfo_i^t, P_{gen\_story})$。
- **MEM（时序知识图谱）**：以四元组 <主体，动作，客体，章节索引> 存储内容；先用 LLM 抽取三元组并添加章节编号构成四元组存入 TKG；查询时先做实体基于四元组检索，再用 LLM 进行语义相关性过滤（余弦相似度阈值 0.75），返回 top-k 最相关信息。
- **Temporal Conflict Analyzer**：将 TKG 中所有四元组按规则分组（同主体/时间顺序/因果关系等），描述为自然语言后用 LLM 判断是否存在冲突；冲突率 $CR. = m/N \times 100\%$，其中 N 为总四元组数，m 为冲突四元组数。

## 实验与结果
- **数据集**：采用 DOC 数据集的 20 个由 InstructGPT-3-175B 生成的故事前提（含场景设定、角色介绍、剧情要求），每个前提生成 20 篇长故事。
- **基线方法**：纯提示 LLM（Llama3-70B-Instruct、Qwen1.5-72B-Chat）、Re3（Yang et al., 2022）、DOC（Yang et al., 2023）、AgentWriter（Bai et al., 2024）。
- **主要结果（Table 1）**：
  - 最强结果：DOME（Qwen1.5-72B-Chat）词数达 7113.75，Ent-2 = 12.29（较 Qwen1.5-72B-Chat 基线提升 35.7%），CR. = 0.56（降低 15.2%），全部五项人工评估指标（PCo., PCoh., Rel., Int., Ecoh.）均排名第一。
  - 较 Re3：Ent-2 提升 6.3%，CR. 降低 27.3%。
  - 较 DOC：CR. 降低约 53.7%（1.21 → 0.56）。
- **消融实验（Table 2）**：移除 MEM 后 CR. 从 0.56 升至 4.52（提升 707%），Ent-2 从 12.29 降至 10.00；移除 DHO 后所有人工评估指标均显著下降，验证两模块均有效。
- **可扩展性**：在 Yi1.5-34B-Chat 上 Ent-2 提升超 29%，在 Llama3-70B-Instruct 上 CR. 降低超 18%。
- **对比 AgentWriter**：DOME 生成字数约为其 2 倍，CR. 降至 1/4，Ent-2 提升 1.16。

## 相关工作脉络
- **Plan-and-write 框架（Yao et al., 2019；Yang et al., 2022, 2023）**：将生成过程分为规划和写作两个阶段；本文在此框架基础上引入动态大纲调整机制，解决了固定大纲无法适应写作不确定性的问题。
- **交互式故事生成（Brahman et al., 2020；Zhou et al., 2023/RecurrentGPT）**：通过人类交互替代预生成大纲；本文认为该方法缺乏宏观叙事规划，DHO 通过小说写作理论提供高层结构指导，兼顾灵活性与完整性。
- **KG 增强 LLM 推理（Zhang et al., 2024；Wen et al., 2024；Sun et al., 2022）**：将 KG 知识与输入直接拼接或在 token 层融合；本文的独特之处在于使用 TKG 存储时序化叙事信息，并引入 LLM 语义过滤器保障检索内容的相关性和简洁性。
- **长篇小说生成 SOTA（DOC Yang et al., 2023；Re3 Yang et al., 2022）**：DOC 使用详细大纲控制故事连贯性；Re3 通过递归重提示和修订生成长故事；本文在两者基础上引入动态调整和外部记忆机制，进一步降低冲突率。
- **AgentWriter（Bai et al., 2024）**：基于 Agent 的长文本生成方法；本文方法在生成长度、冲突率和多样性上均全面优于 AgentWriter，且计算开销更低。

## 局限性与未来方向
- 实验数据量有限，缺乏专门针对长篇小说生成的标准数据集，仅沿用了 DOC 的 20 个前提。
- 框架依赖大量 LLM API 调用（平均每篇故事约 200 次），生成耗时约 4 小时（7000 词），限制了在付费闭源 LLM 上的实际应用。
- 当前提示词基于人工经验设计，自动提示方法可能难以捕捉长篇小说生成的微妙上下文需求。
- 缺乏成熟的自动评估指标体系，部分质量维度仍依赖人工评估。
- 未来方向包括：优化提示词以实现自动化、减少 API 调用次数以提升生成速度、拓展更多评估基准。

## 研究启发与可借鉴点
- **理论驱动的大纲生成**：将小说写作理论（如 Campbell 五阶段理论）显式融入 prompt 引导粗大纲规划，这一思路可迁移到其他需要结构化输出的长文本生成任务（如剧本、报告）。
- **KG + LLM 语义过滤的记忆机制**：MEM 中"KG 检索 + LLM 语义过滤"的两阶段设计，兼顾了结构化知识的精确检索与自然语言的语义理解，可作为长上下文记忆模块的通用范式。
- **时序知识图谱用于冲突检测**：Temporal Conflict Analyzer 将冲突检测形式化为 TKG 中的四元组分组与 LLM 判断，思路可推广至任何需要一致性校验的长文本生成场景。
- **动态规划-写作交替框架**：DHO 中粗大纲先行、细大纲随写随调的策略，可有效平衡"全局规划"与"局部灵活"的矛盾，适合需要长程规划的序列生成任务。

## 关键术语表
**DOME**：Dynamic Hierarchical Outlining with Memory-Enhancement，论文提出的长篇小说生成框架名称。
**DHO（Dynamic Hierarchical Outline）**：动态层次大纲机制，由粗大纲和细大纲组成，粗大纲基于小说写作理论生成以确保情节完整，细大纲在写作过程中动态调整以适应不确定性。
**MEM（Memory-Enhancement Module）**：记忆增强模块，基于时序知识图谱（TKG）存储和检索已生成故事内容，为后续生成提供相关上下文以减少冲突。
**Temporal Knowledge Graph（TKG）**：时序知识图谱，以四元组 <主体，动作，客体，章节索引> 形式存储叙事信息，支持按时间和实体检索。
**CR.（Conflict Rate）**：冲突率，通过 TKG 中冲突四元组占总四元组比例自动计算的上下文一致性指标。
**Ent-2（Bigram Entropy）**：二元 n-gram 熵，用于评估生成文本词汇多样性的自动指标，值越高代表内容越丰富多样。
**Temporal Conflict Analyzer**：时序冲突分析器，基于 TKG 信息表示规则和 LLM 自动检测长篇小说中上下文冲突的评估工具。
