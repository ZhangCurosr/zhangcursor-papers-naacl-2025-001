# 论文速读：Unfamiliar-Finetuning-Examples-Control-How-Language-Models-H

## 一句话总结
本文揭示大语言模型在面对陌生查询时的幻觉输出会趋近于其微调数据中“陌生样本”的响应分布；基于该机制，作者提出训练“保守奖励模型”，利用同构生成数据抑制奖励高估，从而显著提升 RL 事实性微调在长文生成中的可靠性。

## 研究问题与动机
- LLM 在被询问超出预训练知识范围的概念时，倾向于生成 plausible 但事实错误的幻觉内容，而非表达不确定性或拒答。
- 现有幻觉缓解工作多聚焦于采样策略、检索增强或 SFT 重标注，但对“微调数据分布如何系统性支配测试期陌生输入的响应”这一底层机制缺乏统一解释。
- RL factuality 微调高度依赖奖励模型，但奖励模型自身在陌生输入上同样会产生幻觉（尤其是系统性高估奖励），可能反向误导 RL 训练，该风险尚未被充分揭示与控制。

## 核心贡献（创新点）
1. **提出并验证“陌生微调样本支配幻觉分布”的概念模型**：证明随着输入陌生度上升，模型预测会收敛于由微调陌生样本决定的盲猜分布 $P_{unf}(y)$，而非随机输出。
2. **在 SFT、RL 与奖励模型三类范式下提供统一的控制实验**：系统展示微调/奖励函数的分布设计如何直接决定测试期陌生输入的响应偏好，填补了机制解释的空白。
3. **提出保守奖励模型（Conservative Reward Models）学习策略**：利用与目标模型同构的预训练生成数据构造以低奖励为主的陌生样本，避免奖励高估，并将该策略成功应用于长文 RL 事实性微调。

## 方法详解
- **核心假设形式化**：设微调数据集 $\mathcal{D}$ 中陌生样本子集为 $\mathcal{D}_{unf}$。模型对陌生样本难以拟合最优响应，转而最小化整体损失，等价于学习一个与输入无关的盲猜分布：
  $P_{unf}(y) = \arg\min_{P(y)} \sum_{(x_i, s_i) \in \mathcal{D}_{unf}} \mathcal{L}(P(y), s_i)$。
  测试期面对陌生查询时，模型预测会默认趋近 $P_{unf}(y)$。
- **SFT 控制实验**：在 MMLU 中构造陌生样本标签为 50% B / 50% C 的分布，模型在陌生测试输入上预测分布显著趋近该偏置；在 TriviaQA 中将陌生样本重标为 “I don’t know”，模型在陌生输入上几乎全部输出该短语，且输出比例与微调集中陌生样本占比正相关。
- **RL 控制实验**：设计两种奖励函数——惩罚 abstain（奖励 -3）时，$P_{unf}(y)$ 趋近随机猜测；将 abstain 奖励设为 0 时，$P_{unf}(y)$ 趋近拒答分布。实验验证 RL 模型的陌生输入输出同样由奖励函数决定的 $P_{unf}(y)$ 支配。
- **奖励模型控制实验**：构造两组奖励分布（陌生样本全为高奖励 vs 全为低奖励），验证奖励模型在陌生输入上的预测分布随之偏置，说明 RM 幻觉类型可直接被微调分布控制。
- **保守奖励模型学习流程**：① 用目标预训练模型（Llama2 7B）在任务提示上生成响应；② 使用 FActScore 自动标注原子事实真伪并计算奖励；③ 因生成模型与 RM 共享知识库，陌生查询对应的生成响应天然多为低奖励样本；④ 用该数据集微调 RM，使其对陌生输入倾向输出保守/低奖励，避免高估错误生成。
- **长文 Factuality RL 微调**：以标准 SFT 模型为起点，使用保守或标准 RM 提供的奖励信号进行 PPO 训练，对比其在 WikiBios 与 WikiPlots 上的真/假事实产出。

## 实验与结果
- **数据集与模型**：基座模型 Llama2 7B（补充实验含 Mistral 7B）；短问答基准 MMLU、TriviaQA；长文生成基准 WikiBios、WikiPlots；自动评估/标注工具 FActScore。
- **未熟悉度量化**：few-shot 提示预训练模型，以 MMLU 的正确 NLL 或 TriviaQA/长文任务中错误响应比例作为陌生度分数。
- **SFT 结果**：MMLU 与 TriviaQA 均证实，测试输入越陌生，模型预测分布越趋近微调陌生样本的标签分布；重标 “I don’t know” 的模型在陌生查询上几乎全部拒答。
- **RL 结果**：不同奖励函数导致模型在陌生输入下分别趋近“随机猜测”或“稳定拒答”，与 $P_{unf}(y)$ 理论预测完全一致。
- **奖励模型结果**：标准 RM 在陌生输入上大幅高估奖励；保守 RM 预测奖励与地面真值奖励趋势一致，无显著高估。
- **长文生成结果**：RL + 保守 RM 相比标准 SFT 与 RL + 标准 RM，在 WikiBios 与 WikiPlots 上**保持同等或更多真事实的同时，假事实数量显著下降**；随着输入陌生度增加，标准 SFT 假事实持续膨胀，而保守 RM 的 RL 微调保持稳定优势。
- **最强结果**：RL + Conservative RM 在长文事实性生成上全面优于 baseline，是本文验证的最强配置。

## 相关工作脉络
- **LLM 幻觉成因研究**（Mallen 2023, Kandpal 2023, Kalai & Vempala 2023）：指出训练数据稀疏概念易引发幻觉；本文进一步揭示幻觉内容并非随机，而是镜像微调陌生样本分布。
- **SFT 不确定性表达**（Lin 2022, Zhang 2023a）：通过重标注难例为拒答提升事实性；本文在机制层面解释该现象，并统一推广至 RL 与 RM 场景。
- **RLHF / 事实性 RL 微调**（Ouyang 2022, Tian 2023a, Sun 2023）：关注 RL 提升指令跟随与事实性；本文指出 RL 成败的关键瓶颈之一是 RM 自身的幻觉，并提出保守 RM 训练协议。
- **奖励模型校准与幻觉**：现有工作多关注 RM 偏好建模或校准偏差；本文首次系统论证 RM 对陌生输入的高估偏差会直接破坏下游 RL factuality 微调的可靠性。
- **细粒度事实评估**（FActScore, Min 2023）：本文将其同时作为评估指标与自动奖励标注管道，验证了“事实分解→奖励量化→RL 微调”闭环的可行性。

## 局限性与未来方向
- 概念模型仅针对“完全陌生”样本，现实中大量查询处于“部分熟悉”的光谱中，缺乏对中间地带的细致刻画。
- 实验任务集中于传记与影视/书籍剧情生成，尚未在通用对话、代码生成或更多样化的长文场景中验证泛化性。
- 保守奖励模型仍需借助 FActScore 等外部管线获取地面真值奖励进行标注，在极低资源或专业垂直领域仍存在标注成本挑战。
- 未来方向包括：探索无需外部标注的自动陌生样本筛选机制、将分布盲猜理论推广至多模态与 agent 规划场景、以及刻画“部分熟悉”输入下的连续响应迁移轨迹。

## 研究启发与可借鉴点
- **机制驱动的对照实验设计**：通过隔离“熟悉/陌生”维度构造可控分布，能清晰剥离微调策略的真实效应，该范式适用于任何“分布偏移下的 LLM 行为归因”研究。
- **同构生成数据校准奖励模型**：利用目标模型自身生成的响应构建低奖励陌生样本训练 RM，是一种低成本、抗高估的 RM 校准手段，可直接迁移至任意 RLHF/RLAIF pipeline。
- **未熟悉度评分作为数据筛选器**：few-shot 预训练模型预测偏差（NLL/错误率）可作为自动阈值，用于清洗、重标注或配比微调数据，降低下游幻觉风险。
- **长文事实性 RL 的自动化奖励构造**：将 FActScore 的原子事实分解与真伪判定直接转化为稠密奖励信号，为长文事实一致性微调提供了可复用的工程方案。
- **与本团队结合机会**：若团队关注 RAG 幻觉缓解、RLHF 训练稳定性或领域小模型微调，可将“陌生样本分布控制”思想前置到 SFT 数据配比或 RM 预训练阶段，显著降低长程生成中的事实漂移。
